# قاعدة بيانات مدرسة التميز 🎓

مشروع تدريبي لإنشاء قاعدة بيانات لمدرسة التميز للتعليم الثانوي باستخدام MySQL، تطبيقًا لما تعلمته في دورة SQL 101 من منصة سطر التابعة لأكاديمية طويق.

## فكرة المشروع

تنظيم معلومات الطلاب والمعلمين والمواد الدراسية في قاعدة بيانات واحدة، والتدرّب على أوامر SQL الأساسية لإنشاء البيانات وعرضها وتعديلها.

## الأدوات المستخدمة

- MySQL
- MySQL Workbench

## الجداول

### الطلاب — students

يحتوي على بيانات 30 طالبًا وطالبة:
- الرقم التسلسلي.
- اسم الطالب.
- تاريخ الميلاد.
- الجنس: F أو M.
- تاريخ الالتحاق.
- البريد الإلكتروني.
- المستوى الدراسي: من 1 إلى 6.
- المسار: علمي أو انساني.
- المعدل التراكمي: من 100.

### المعلمون — teachers

يحتوي على بيانات 10 معلمين ومعلمات:
- الرقم التسلسلي.
- اسم المعلم.
- تاريخ الميلاد.
- الجنس: F أو M.
- البريد الإلكتروني.
- رقم المكتب.

### المواد — subjects

يحتوي على 6 مواد دراسية:
- الرقم التسلسلي.
- اسم المادة.

يُغيَّر اسم جدول subjects إلى courses في نهاية السكربت، تطبيقًا لأمر إعادة تسمية الجداول.

## المهارات المطبّقة

- إنشاء قاعدة بيانات باستخدام CREATE DATABASE.
- إنشاء الجداول وتحديد المفتاح الأساسي باستخدام CREATE TABLE.
- عرض أسماء الجداول باستخدام SHOW TABLES.
- إدخال البيانات باستخدام INSERT INTO.
- عرض البيانات باستخدام SELECT.
- ترتيب الطلاب تصاعديًا حسب الاسم باستخدام ORDER BY.
- استخدام اسم مستعار للعمود باستخدام AS.
- تعديل بريد طالب ورقم مكتب معلم باستخدام UPDATE وWHERE.
- تغيير اسم جدول باستخدام ALTER TABLE.
- كتابة تعليقات لتوضيح الأوامر.

## ملفات المشروع

- school.sql: أوامر إنشاء قاعدة البيانات والجداول وإدخال البيانات والاستعلام عنها وتعديلها.
- README.md: شرح المشروع وطريقة تشغيله.

## طريقة التشغيل

1. تأكد من تثبيت MySQL وتشغيل الخادم.
2. افتح MySQL Workbench واتصل بالخادم.
3. افتح ملف school.sql.
4. نفّذ الأوامر بالترتيب على قاعدة بيانات جديدة.
5. استعرض نتائج الاستعلامات في نافذة النتائج.

يمكن تنفيذ الملف كاملًا في التشغيل الأول، أو تحديد كل أمر وتنفيذه منفردًا بالترتيب.

## ملاحظات

- جميع الأسماء وبيانات الاتصال افتراضية لأغراض التدريب.
- قد تؤدي إعادة تنفيذ أوامر الإنشاء والإدخال إلى أخطاء بسبب وجود الجداول أو تكرار الأرقام التسلسلية.
- يمكن تكرار استعلامات SELECT لعرض البيانات دون تغييرها.
- بعد إعادة تسمية جدول subjects، يجب استخدام اسمه الجديد courses.
- المشروع تدريبي مستقل، وليس مشروعًا رسميًا تابعًا لأكاديمية طويق.
