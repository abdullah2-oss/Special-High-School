# Special-High-School
مشروع قاعدة بيانات لمدرسة التميز للتعليم الثانوي، باستخدام MySQL، تطبيقًا لمهارات دورة SQL 101 من منصة سطر التابعة لأكاديمية طويق. يضم بيانات افتراضية لـ30 طالبًا و10 معلمين و6 مواد، ويوضح إنشاء قاعدة البيانات والجداول، وإدخال السجلات وعرضها وترتيبها، واستخدام الأسماء المستعارة، وتحديث البيانات، وتغيير أسماء الجداول، مع تعليقات لشرح الأوامر.
